# app/explorer/components

- `ExplorerShell.tsx` — three-pane layout and shared state for the Explorer.
- `UploadPanel.tsx` — dataset upload form: name, description, tags, file.
- `CatalogList.tsx` — searchable dataset list.
- `DatasetView.tsx` — dataset header, "Ask in chat" deep link, "Download report".
- `PreviewTable.tsx` — paged (50/page) preview table with inferred type badges.
- `ChartBuilder.tsx` — chart type / x / y / aggregate picker, save, and export (PNG/PDF).
- `ReportsList.tsx` — saved reports list; highlights the active one.
